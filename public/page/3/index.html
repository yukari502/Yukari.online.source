性染色体与性别决定

3.1.1 性别与性染色体

历史发现 - Hening (1891) 首次在半翅目昆虫的精母细胞中发现了 X, Y 染色体，但并未发现它们与性别相关。 - Meclcrus (1902) 首次认为 X 染色体与性别有关。 - Wilson 等 (1905) 在直翅目与半翅目昆虫中证明，雌体有两套常染色体 + 两条 X 染色体，雄体有两套常染色体 + 1X（XX-XO）。 基础概念 - 性染色体 (sex chromosome)：在生物许多成对的染色体中，直接与性别决定有关的一个或一对染色体。 - 常染色体 (autosome)：性染色体以外的染色体，常用“A”表示。 - 性比 (sex ratio, SR)：两性生物中雄性:雌性=1:1，此为一个恒定的比率。
