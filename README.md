# Yukari's LEAF 🍃

Welcome to my personal blog space! 

This repository houses the source code and articles for **Yukari.online**. Here, I share my thoughts, learnings, and experiences across various topics in a quiet, "Wabi-sabi" inspired corner of the internet.

## 🌟 About the Blog

The content primarily revolves around:
- **Tech & Tinkering**: Explorations into hardware, software, and DIY projects (like Raspberry Pi MIDI keyboards).
- **Language Learning**: My personal journey and insights into language acquisition.
- **Odds and Ends**: Miscellaneous thoughts, daily records, and everything else that catches my interest.
