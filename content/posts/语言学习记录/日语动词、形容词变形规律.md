### 日语动词变形规律

#### 动词分类基础
* **一类动词（五段动词）：** 词尾以「う」段假名结尾（如：書く、話す、飲む）。
* **二类动词（一段动词）：** 词尾以「る」结尾，且「る」前面的假名属于「い」段或「え」段（如：見る、食べる）。
* **三类动词（不规则动词）：** 仅有两个基础词，即「する」（做）和「くる」（来）。

#### 1. 辞书形 (字典形 / 原形)
* **作用：** 动词的原始形态，字典中查找单词时使用的形式。在口语或非正式场合中，直接用于表示现在或未来的肯定动作。
* **变化规则：** 无需变化，即动词本身的形态。

#### 2. ます形 (敬体 / 礼貌形)
* **作用：** 用于长辈、上级或不熟悉的人之间，表达礼貌和敬意。表示现在进行或未来将要发生的肯定动作。

| 动词分类 | 变化规则 | 示例 (辞书形 ➔ ます形) |
| :--- | :--- | :--- |
| **一类动词** | 词尾由「う」段假名变为同行的「い」段假名，加「ます」 | 書く ➔ 書きます |
| **二类动词** | 去掉词尾的「る」，加「ます」 | 食べる ➔ 食べます |
| **三类动词** | する ➔ します；くる ➔ きます | 勉強する ➔ 勉強します |

#### 3. て形 (连接 / 中顿 / 请求)
* **作用：** 核心语法形态之一。用于连接多个动作、表达动作的先后顺序、表示正在进行的状态（搭配「いる」）、或提出请求（搭配「ください」）。

| 动词分类 / 词尾 | 变化规则 | 示例 (辞书形 ➔ て形) |
| :--- | :--- | :--- |
| **一类 (く、ぐ)** | 变为「いて」、「いで」 (例外：行く ➔ 行って) | 書く ➔ 書いて；泳ぐ ➔ 泳いで |
| **一类 (う、つ、る)**| 变为促音「って」 | 買う ➔ 買って；待つ ➔ 待って |
| **一类 (ぬ、ぶ、む)**| 变为拨音「んで」 | 飲む ➔ 飲んで；遊ぶ ➔ 遊んで |
| **一类 (す)** | 变为「して」 | 話す ➔ 話して |
| **二类动词** | 去掉词尾的「る」，加「て」 | 見る ➔ 見て；食べる ➔ 食べて |
| **三类动词** | する ➔ して；くる ➔ きて | 散歩する ➔ 散歩して |

#### 4. た形 (过去式)
* **作用：** 表示动作已经完成或发生在过去。用于非正式场合的过去时态表达。
* **变化规则：** 与「て形」的变形规则完全一致，仅需将变化后的「て」或「で」替换为「た」或「だ」。
    * 書く ➔ 書いた
    * 飲む ➔ 飲んだ
    * 食べる ➔ 食べた

#### 5. ない形 (否定形)
* **作用：** 表示动作的否定（不做某事）。常用于非正式场合，或接续其他语法。

| 动词分类 | 变化规则 | 示例 (辞书形 ➔ ない形) |
| :--- | :--- | :--- |
| **一类动词** | 词尾「う」段变为同行「あ」段，加「ない」 (例外：词尾为「う」时变为「わ」) | 書く ➔ 書かない；買う ➔ 買わない |
| **二类动词** | 去掉词尾的「る」，加「ない」 | 寝る ➔ 寝ない |
| **三类动词** | する ➔ しない；くる ➔ こない | 残業する ➔ 残業しない |

#### 6. 意志形
* **作用：** 表达说话人的意愿、决心，或用于非正式场合提议、邀请他人一起做某事。

| 动词分类 | 变化规则 | 示例 (辞书形 ➔ 意志形) |
| :--- | :--- | :--- |
| **一类动词** | 词尾「う」段变为同行「お」段，加「う」 | 行く ➔ 行こう |
| **二类动词** | 去掉词尾的「る」，加「よう」 | 食べる ➔ 食べよう |
| **三类动词** | する ➔ しよう；くる ➔ こよう | 会议する ➔ 会议しよう |

#### 7. 可能形
* **作用：** 表示具有某种能力，或客观条件允许做某事（能够做某事）。

| 动词分类 | 变化规则 | 示例 (辞书形 ➔ 可能形) |
| :--- | :--- | :--- |
| **一类动词** | 词尾「う」段变为同行「え」段，加「る」 | 読む ➔ 読める |
| **二类动词** | 去掉词尾的「る」，加「られる」 | 起きる ➔ 起きられる |
| **三类动词** | する ➔ できる；くる ➔ こられる | 運転する ➔ 運転できる |

#### 8. ば形 (条件形)
* **作用：** 表达假设或条件，意思是“如果做了某事，则会发生某种结果”。

| 动词分类 | 变化规则 | 示例 (辞书形 ➔ ば形) |
| :--- | :--- | :--- |
| **一类动词** | 词尾「う」段变为同行「え」段，加「ば」 | 降る ➔ 降れば |
| **二类动词** | 去掉词尾的「る」，加「れば」 | 見る ➔ 見れば |
| **三类动词** | する ➔ すれば；くる ➔ くれば | 練習する ➔ 練習すれば |

#### 9. 被动形
* **作用：** 表示主语承受某个动作，或受到某人/某事的影响（被做某事）。

| 动词分类 | 变化规则 | 示例 (辞书形 ➔ 被动形) |
| :--- | :--- | :--- |
| **一类动词** | 词尾「う」段变为同行「あ」段，加「れる」 | 叱る ➔ 叱られる |
| **二类动词** | 去掉词尾的「る」，加「られる」 | 褒める ➔ 褒められる |
| **三类动词** | する ➔ される；くる ➔ こられる | 発见する ➔ 発见される |

#### 10. 使役形
* **作用：** 表示强制、命令某人做某事，或允许、放任某人做某事（让/叫某人做某事）。

| 动词分类 | 变化规则 | 示例 (辞书形 ➔ 使役形) |
| :--- | :--- | :--- |
| **一类动词** | 词尾「う」段变为同行「あ」段，加「せる」 | 休む ➔ 休ませる |
| **二类动词** | 去掉词尾的「る」，加「させる」 | 食べる ➔ 食べさせる |
| **三类动词** | する ➔ させる；くる ➔ こさせる | 勉強する ➔ 勉強させる |

#### 11. 命令形与禁止形
* **作用：** 命令形用于强烈要求他人做某事；禁止形用于强烈要求他人绝对不要做某事。
* **变化规则：**
    * **命令形：**
        * 一类：词尾「う」段变「え」段（走る ➔ 走れ）。
        * 二类：去「る」加「ろ」（逃げる ➔ 逃げろ）。
        * 三类：する ➔ しろ；くる ➔ こい。
    * **禁止形：** 所有动词一律使用「辞书形（原形）+ な」（走るな、逃げるな、するな）。

### 日语形容词与副词变形规律

注：「いい」（好）是特殊词汇，变形时需先恢复为其古语词根「よい」，再按一类形容词规则变化。

#### 1. い形容词（一类形容词）
此类词在辞书形中均以假名「い」结尾。

| 形态 | 变化规则 | 示例 (以「高い」为例) | 作用 |
| :--- | :--- | :--- | :--- |
| **辞书形** | 保持原形 | 高い | 直接修饰名词，或作句尾谓语陈述现在状态。 |
| **否定形** | 去「い」加「くない」 | 高くない | 表达不具备某种状态。 |
| **过去形** | 去「い」加「かった」 | 高かった | 表达过去曾经具备的状态。 |
| **过去否定形** | 去「い」加「くなかった」 | 高くなかった | 表达过去不具备某种状态。 |
| **て形** | 去「い」加「くて」 | 高くて | 连接其他形容词或分句，表示状态的并列或说明原因。 |
| **副词化** | 去「い」加「く」 | 高く | 转化为副词，修饰其后的动词动作。 |
| **ば形** | 去「い」加「ければ」 | 高ければ | 表达假设条件。 |
| **名词化** | 去「い」加「さ」 | 高さ | 将形容词转化为表示程度、尺寸或性质的名词。 |

#### 2. な形容词（二类形容词 / 形容动词）
此类词的词干不以「い」结尾。

| 形态 | 变化规则 | 示例 (以「静か」为例) | 作用 |
| :--- | :--- | :--- | :--- |
| **修饰名词** | 词干加「な」 | 静かな | 作为定语，直接修饰其后的名词。 |
| **谓语形** | 词干加「だ」或「です」 | 静かだ / 静かです | 位于句末，肯定陈述现在的状态。 |
| **否定形** | 词干加「ではない」/「じゃない」 | 静かではない | 表达不具备某种状态。 |
| **过去形** | 词干加「だった」/「でした」 | 静かだった | 表达过去曾经具备的状态。 |
| **过去否定形** | 词干加「ではなかった」/「じゃなかった」 | 静かではなかった | 表达过去不具备某种状态。 |
| **て形** | 词干加「で」 | 静かで | 连接分句，表示状态并列或说明原因。 |
| **副词化** | 词干加「に」 | 静かに | 转化为副词，修饰其后的动词动作。 |
| **ば形** | 词干加「なら」或「ならば」 | 静かなら | 表达假设条件。 |
